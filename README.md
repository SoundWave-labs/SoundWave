## ✨ Features

- **🎵 100% Free & Ad-Free** — Every single feature is unlocked out of the box with zero paywalls, zero ads, and no login required.
- **📥 Offline `.m4a` Downloads** — Save songs directly to your device and listen anywhere without internet.
- **🎤 Real-Time Synced Lyrics** — Follow along line by line while listening.
- **🌍 Smart Discovery & Global Charts** — Personalized mixes, Global Top 50, Fresh Releases, Moods & Activities, and full Artist & Album pages.
- **📚 Complete Personal Library** — Unlimited Playlists, Favorites (Songs, Artists & Albums), Listening History, and custom drag-and-drop ordering.
- **💾 Backup & Restore (`.swbackup`)** — Export and restore your entire library, playlists, themes, and preferences in one tap.
- **🎨 7 Studio Themes (Including True OLED Black)** — Switch themes live on mobile and desktop.
- **🌐 Trilingual UI** — Built-in **English**, **Français**, and **العربية** language support in Settings.
- **⚡ Automatic 1-Tap In-App Updates** — SHA-256 verified OTA updates on both Android and Linux.

## ⬇️ Download & Install

### 📱 Android

1. Open the [**Latest Release**](https://github.com/SoundWave-labs/SoundWave/releases/latest) page (or grab it from [@SWA_SoundWaveAPP_bot](https://t.me/SWA_SoundWaveAPP_bot)).
2. Download the APK matching your device:
   - **`SoundWave-vX.X.X-arm64-v8a.apk`** — Modern Android phones *(Recommended for 99% of devices)*
   - **`SoundWave-vX.X.X-armeabi-v7a.apk`** — Older 32-bit Android phones
   - **`SoundWave-vX.X.X-x86_64.apk`** — Android emulators / x86 tablets
3. Tap the downloaded APK to install.
   > **Tip:** If Google Play Protect asks to *"Scan app"* on first install, tap **Scan app** — it verifies the package as clean and completes installation normally.

---

### 🐧 Linux Desktop (Ubuntu / Debian / Arch / Fedora)

**1-Line Terminal Installer (Recommended):**
```bash
curl -fsSL https://raw.githubusercontent.com/SoundWave-labs/SoundWave/main/install-linux.sh | sudo bash
```

**Or Manual Download:**
- **Debian / Ubuntu / Mint / Pop!_OS:** Download the `.deb` package from [**Latest Release**](https://github.com/SoundWave-labs/SoundWave/releases/latest) and run:
  ```bash
  sudo apt install ./SoundWave-*-linux-amd64.deb
  ```
- **Other Distros:** Download `SoundWave-*-linux-x64.tar.gz`, extract it, and run `./soundwave`.
